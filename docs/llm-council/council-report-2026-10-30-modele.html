LLM Council : quel cœur de modèle pour le MVP ?

ResNet-50 + mapping ImageNet (spec) · CLIP zero-shot · hybride — API de catégorisation Marketplace (Ynov)

Verdict : option C, séquencée

ResNet-50 reste le chemin de production pour les itérations 1 → 6. Le code est construit autour d'une interface Predictor commune et d'un seuil par modèle pour brancher CLIP sans réécriture. L'accuracy est mesurée dès l'itération 2 sur un jeu de test proxy public, puis sur des photos réelles. CLIP devient principal seulement si la mesure le justifie (ResNet < 80 %, CLIP ≥ 80 % avec p95 < 500 ms). Le critère 80 % est conservé.

Première action : constituer le jeu d'évaluation étiqueté et mesurer ResNet dès que l'itération 2 tourne.

Où le conseil est d'accord

  • Le module note l'industrialisation : la chaîne complète passe avant le choix du modèle.
  • ResNet + mapping manuel risque de rater 80 % (vêtements, meubles, électroménager mal couverts).
  • Mesurer tôt, ne jamais trancher à l'aveugle.
  • Pour CLIP : n'exporter que l'encodeur image, embeddings texte pré-calculés.

Angles morts relevés en revue croisée

  • Biais d'un jeu de test étiqueté par l'étudiant lui-même.
  • Valider la déviation avec le formateur (un mail suffit).
  • Le seuil 0,6 n'est pas transposable d'un modèle à l'autre : il faut un seuil par modèle.
  • Latence p95 et taille Docker de CLIP non chiffrées.
  • Troisième voie : classifieur à vocabulaire plus riche (ImageNet-21k, ConvNeXt/ViT).
Executor

Option C avec ordre strict : itérations 1-3 avec ResNet, 100 photos étiquetées tout de suite, mesure immédiate ; CLIP en PyTorch pur après l'itération 6 ; tableau MLflow à trois lignes. Garde-fou : abandon de CLIP si plus d'une semaine de retard.

Expansionist

CLIP comme argument de soutenance : arbitrage précision vs coût dans MLflow, « coût par point d'accuracy » en FinOps, ajout d'une catégorie en direct via un JSON.

Contrarian

Le critère 80 % condamne l'option A ; la cohérence avec une spec qu'on a rédigée soi-même est un faux argument ; C double le travail. Spike de 2 h sur CLIP avant de trancher.

First Principles

Le modèle n'est que la charge utile. Remplacer « 80 % » par « perte ≤ 2 pts entre lourd et optimisé ». CLIP s'exporte simplement si on ne garde que l'encodeur image.

Outsider

Un juré voit « Autre » sur un canapé et conclut que ça ne marche pas. CLIP principal, ResNet baseline, décision présentée comme une mesure d'ingénieur.
